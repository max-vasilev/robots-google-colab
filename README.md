# robots-google-colab

Обучение гуманоида **Unitree G1** ходьбе в [MuJoCo Playground](https://github.com/google-deepmind/mujoco_playground) на бесплатном GPU Google Colab (T4). Локально на Mac без NVIDIA не обучаем.

## Что внутри

- `g1_locomotion.ipynb` — ноутбук на основе `learning/notebooks/locomotion.ipynb` из Playground, с тремя ячейками для среды `G1JoystickFlatTerrain`: настройка, обучение PPO, видео.

## Как запустить

1. Открыть ноутбук в Colab → **Среда выполнения → Сменить среду выполнения → T4 GPU**.
2. Выполнить ячейку с фиксированными версиями пакетов, затем **Среда выполнения → Перезапустить сеанс**.
3. Выполнить ячейки установки и импорта сверху, затем три ячейки G1.

## Грабли и решения

| Проблема | Решение |
|---|---|
| `warp-lang is not installed` | `env_cfg.impl = "jax"` — классический MJX вместо MuJoCo Warp |
| `jax.core.get_opaque_trace_state ... removed`, `jax.device_put_replicated is deprecated` | в Colab слишком новый JAX; ставим проверенный набор из `uv.lock` Playground (ниже) и перезапускаем сеанс |
| `KeyError` на теле `"torso"` при рендере | у G1 тело называется `torso_link`; используем `eval_env._torso_body_id` |

Проверенные версии:

```
pip install "jax[cuda12]==0.6.2" brax==0.14.2 flax==0.11.2 orbax-checkpoint==0.11.31 mujoco==3.6.0 mujoco-mjx==3.6.0
```

## Среда G1JoystickFlatTerrain

- **Вход политики (103 числа):** скорость и угловая скорость таза, направление гравитации, команда джойстика, углы/скорости/прошлые действия всех 29 суставов, фаза шага. К датчикам добавляется шум.
- **Выход (29 чисел):** смещения целевых углов суставов: `цель = стойка + action × 0.5`. Частота 50 Гц, физика 500 Гц.
- **Обучение:** PPO (brax), сети 512-256-128; critic видит привилегированные наблюдения. Толчки робота и domain randomization для устойчивости.

## Эксперименты с наградой

| Параметр | По умолчанию | Идея |
|---|---|---|
| `reward_config.max_foot_height` | 0.15 | 0.3 — высокий шаг, 0.07 — семенящий |
| `reward_config.scales.energy` | 0 | −0.001 — экономная, плавная походка |
| `reward_config.scales.pose` | −0.1 | 0 — свободные руки, −1.0 — «солдатик» |
